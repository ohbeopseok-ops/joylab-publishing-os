# JoyLab Search Console Scorecard V1.0

기준 도메인: `https://aijoylab.kr`

목적: 새 사이트의 초기 색인 안정성과 검색 유입 성장 여부를 7일·30일 단위로 같은 기준에서 확인한다.

## 1. 7일 Launch Health

초기 7일은 트래픽 목표보다 **검색엔진이 사이트를 정상적으로 읽고 있는지**를 확인하는 구간이다.

| 항목 | 확인값 | PASS 기준 | 이상 시 액션 |
| --- | --- | --- | --- |
| Sitemap | 상태 | 성공 | sitemap.xml·robots.txt 재검증 |
| 색인 비율 | 색인 페이지 / 게시 페이지 | 100% 목표, 최소 90% | URL 검사·canonical·robots 확인 |
| 크롤링 오류 | 서버/리디렉션 오류 | 0건 | Cloudflare·Worker 응답 점검 |
| 검색 노출 시작 | 노출수 | 1회 이상 발생 여부 | 7일 내 0이면 제목·주제·발견 경로 점검 |
| 검색어 발견 | 노출 발생 쿼리 수 | 증가 여부 | 주제 표현과 본문 키워드 재점검 |
| HTTPS | 유효 페이지 | 100% | 인증서·리디렉션 점검 |

### 7일 판정

- **PASS**: sitemap 성공 + 색인 90% 이상 + 치명적 크롤링 오류 0건
- **WATCH**: 색인은 정상이나 노출이 아직 0 또는 매우 적음
- **FIX**: 색인 비율 90% 미만 또는 페이지 가져오기 실패 발생

신규 사이트의 첫 7일에는 클릭 수를 핵심 KPI로 사용하지 않는다. 노출과 색인 안정화가 먼저다.

## 2. 30일 Growth Scorecard

30일 구간부터는 기술 상태와 함께 **검색 수요와 클릭 전환**을 본다.

| 영역 | 가중치 | 핵심 지표 | 판단 기준 |
| --- | ---: | --- | --- |
| Index Health | 25 | 색인 비율, 제외·오류 페이지 | 게시 페이지의 90% 이상 색인 유지 |
| Discovery | 25 | 노출수, 노출 페이지 수, 노출 쿼리 수 | 7일 이동평균이 우상향하는지 확인 |
| Click Growth | 20 | 클릭수 | 전월·전주 대비 방향성 확인 |
| CTR Quality | 15 | CTR | 노출 50회 이상 페이지부터 해석 |
| Rank Momentum | 15 | 평균 게재순위, Top20/Top10 쿼리 수 | 상위 20위 진입 쿼리 증가 여부 |

총점: 100점

### 점수 규칙

**Index Health 25점**
- 95% 이상: 25
- 90~94%: 20
- 80~89%: 10
- 80% 미만: 0

**Discovery 25점**
- 최근 7일 노출이 이전 7일보다 증가: 15
- 노출 페이지 수 증가: 5
- 노출 쿼리 수 증가: 5

**Click Growth 20점**
- 클릭 발생 및 최근 7일 증가: 20
- 클릭 발생, 정체: 12
- 클릭 0: 0

**CTR Quality 15점**
- 노출 50회 이상 페이지 중 CTR 개선: 15
- 데이터 부족: N/A 처리, 총점에서 임시 제외
- CTR 하락 지속: 5

**Rank Momentum 15점**
- Top10 쿼리 증가: 15
- Top20 쿼리 증가: 10
- 평균 순위만 개선: 5
- 악화: 0

## 3. JoyLab 운영 액션 룰

### A. 색인은 됐지만 노출이 없다

- 제목과 H1이 실제 검색 표현을 포함하는지 확인
- 본문 첫 300자 안에 핵심 질문과 답이 있는지 확인
- 내부링크 2개 이상 연결
- 같은 주제의 후속 글을 추가해 토픽 클러스터를 만든다

### B. 노출은 많은데 클릭이 없다

노출 100회 이상인데 클릭이 거의 없다면 제목·메타 설명을 우선 재작성한다.

특히 평균 순위 5~15위 구간은 제목의 구체성, 숫자, 비교 대상, 검색 의도를 조정한다.

### C. 순위 11~20위 쿼리가 생긴다

가장 먼저 확장할 후보이다.

- 기존 글에 해당 질문을 H2로 추가
- 별도 후속 글 작성
- 원문과 후속 글을 양방향 내부링크

### D. 30일 동안 노출이 거의 없는 글

단순히 기다리지 않는다.

- 검색 의도와 제목 불일치 확인
- 유사 글과 통합 여부 검토
- 더 구체적인 롱테일 키워드로 재포지셔닝
- 투자형 글이라면 검색형 기초 글을 앞단에 추가

## 5. 초기 Gold Case 기준

첫 10개 글까지는 절대 트래픽 목표보다 아래 네 가지를 우선한다.

1. 모든 게시 글이 sitemap에 포함된다.
2. 게시 후 7일 이내 색인 여부를 확인한다.
3. 각 글에 최소 2개의 문맥형 내부링크를 만든다.
4. 30일 데이터가 쌓이면 노출 쿼리를 기준으로 다음 글을 결정한다.

초기 콘텐츠 계획은 `3개 → 10개 → 30개` 순서로 검증하며, 검색 데이터 없이 대량 생산하지 않는다.

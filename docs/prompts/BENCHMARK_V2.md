# Benchmark Prompt V2

Use for product tests, tool comparisons, field trials, measured experiments.

## Required output
1. Hypothesis
2. Test setup
3. Sample / run conditions
4. Success criteria
5. Raw or summarized results
6. Variance / error / failed runs
7. Limitations
8. Interpretation
9. Decision rule
10. Recheck / replication trigger
11. Sources

## Rules
- Do not generalize beyond the tested sample.
- Report failed runs and human intervention.
- Distinguish measured values from estimates.
- If speed, cost, or quality was not measured, say so explicitly.
- Preserve enough method detail for replication.

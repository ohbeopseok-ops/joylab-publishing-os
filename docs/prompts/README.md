# JoyLab Research V2 Prompt Router

Choose exactly one production prompt before drafting:
- RESEARCH_V2.md — market, company, macro, infrastructure, technology-shift analysis
- FRAMEWORK_V2.md — leadership, performance, fairness, learning, management systems
- GUIDE_V2.md — tools, Codex, AI workflows, operational instructions
- BENCHMARK_V2.md — experiments, comparisons, field tests

All four inherit `docs/JOYLAB_RESEARCH_STANDARD_V2.0.md` and must pass `scripts/audit-research-v2.mjs`.

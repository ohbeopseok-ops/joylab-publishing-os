# Framework Prompt V2

Use for leadership, performance, fairness, coaching, learning, organizational systems.

## Required output
1. Operating problem
2. Evidence / relevant theory or observed data
3. Framework definition
4. Mechanism: why it should work
5. Example / counterexample
6. Failure modes and limits
7. Application steps
8. Metrics
9. Recheck Trigger
10. Sources

## Rules
- Never insert investment-only sections, Bull/Base/Bear, or market disclaimers.
- Distinguish established evidence from JoyLab interpretation.
- A framework must contain observable behaviors or measurable drivers.
- Avoid unsupported universal claims.
- START HERE and related links must remain in the Growth/Leadership pillar unless cross-pillar logic is explicit.

# Guide Prompt V2

Use for Codex, AI tools, workflows, automation, operations.

## Required output
1. User goal
2. Preconditions
3. Exact steps
4. Verification after each critical step
5. Failure modes / rollback
6. Checklist
7. Security / permission boundary where relevant
8. Limits
9. Recheck Trigger
10. Sources / official docs

## Rules
- Prefer first-party product documentation for current behavior.
- Do not write market scenarios or investment disclaimers.
- Separate confirmed product behavior from inference.
- A guide is incomplete if it lacks verification and failure handling.
- Avoid template phrases that do not help complete the task.

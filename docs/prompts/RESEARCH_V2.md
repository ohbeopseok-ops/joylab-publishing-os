# Research Prompt V2

Use for company, market, macro, infrastructure, technology-shift research.

## Required output
1. Research Question
2. Evidence Pack
3. Verified Facts
4. Interpretation
5. JoyLab causal/decision framework
6. Base / upside / downside scenario only when the topic genuinely requires scenarios
7. Counter Evidence / What could break the thesis
8. Watchlist / Action
9. Recheck Trigger
10. Sources

## Rules
- Do not fabricate numbers, quotes, dates, or citations.
- Prefer primary sources.
- Separate FACT from INTERPRETATION.
- Do not use investment disclaimers in non-investment content.
- Every important numeric claim must be traceable to a source.
- State uncertainty and missing evidence.
- Avoid generic JoyLab boilerplate; write a question-specific research brief.
- End with a concrete recheck condition, not a generic conclusion.

## 시리즈 공통 Visual Contract
- 크기: 1200×675 고정
- 포맷: WebP
- 본문 Hero / og:image / twitter:image / Article Schema / 시리즈 카드가 동일 파일을 참조
- 이미지 내부에 제목·작가명·긴 문구 삽입 금지
- 작품 원작 표지·영화 포스터를 복제하지 않고 상징적 장면으로 재해석
- 모바일 390/430에서 핵심 피사체가 잘리지 않도록 중앙~우측 60%에 주요 피사체 배치
- 좌측은 Deep Navy 그라데이션 오버레이가 자연스럽게 먹도록 여백 확보

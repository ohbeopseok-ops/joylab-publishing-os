# JoyLab Gold Case 7~10 Search Intent Backlog V1.0

기준일: **2026-09-10**

목적: 6개 Launch Cohort 이후 글을 바로 양산하지 않고, **검색 의도 중복을 피하면서 기존 클러스터를 확장할 수 있는 4개 후보**를 대기열로 관리한다.

현재 6개 축:

1. HBM 기초
2. 반도체 사이클
3. 외국인 수급
4. 삼성전자 주가 전망
5. SK하이닉스 주가 전망
6. 삼성전자 vs SK하이닉스 비교

원칙은 단순하다. **새 글은 기존 글과 같은 질문에 답하지 않는다.** 각 Gold Case는 검색자가 다른 이유로 검색했을 때 필요한 별도 답을 제공해야 한다.

## Gold Case 7

### 삼성전자 HBM 전망｜인증보다 중요한 양산·수율·이익 기여

**핵심 검색 의도**  
삼성전자 HBM 경쟁력과 향후 실적 기여를 구체적으로 알고 싶은 독자.

**가설 키워드**
- 삼성전자 HBM 전망
- 삼성전자 HBM4
- 삼성전자 HBM 엔비디아
- 삼성전자 HBM 수율

**기존 글과의 역할 분리**
- `what-is-hbm`: HBM 자체를 설명
- `samsung-electronics-outlook`: 삼성전자 전체 주가 판단
- **Gold Case 7**: 삼성전자 안에서 HBM만 깊게 분석

**필수 내부링크**
- HBM 기초
- 삼성전자 주가 전망
- 삼성전자 vs SK하이닉스

**작성 Gate**
- Search Console에서 `삼성전자 + HBM` 조합 쿼리가 발생하거나
- 7D Launch Health가 PASS이고 7~10번 중 우선순위 확인이 필요할 때 작성

## Gold Case 8

**핵심 검색 의도**  
자사주 매입 뉴스가 실제 주가와 주당가치에 어떤 영향을 주는지 알고 싶은 독자.

**가설 키워드**
- 삼성전자 자사주 매입
- 삼성전자 자사주 소각
- 자사주 매입 주가 영향
- 자사주 소각 효과

**기존 글과의 역할 분리**
- `samsung-electronics-outlook`: 전체 펀더멘털 판단
- `foreign-investor-flow`: 수급 해석
- **Gold Case 8**: 주주환원과 자본구조 이벤트 해석

**필수 내부링크**
- 삼성전자 주가 전망
- 외국인 수급
- 반도체 투자 가이드 Pillar

**작성 Gate**
- 삼성전자 자사주 관련 실제 이벤트가 발생하거나

## Gold Case 9

### 원·달러 환율이 한국 주식에 미치는 영향｜외국인 수급·삼성전자와 연결해서 보기

**핵심 검색 의도**  
환율 상승·하락이 코스피, 외국인, 수출주에 어떤 영향을 주는지 이해하려는 독자.

**가설 키워드**
- 원달러 환율 주식 영향
- 환율 오르면 주식
- 원화 강세 외국인 수급
- 환율 삼성전자 영향

**기존 글과의 역할 분리**
- `foreign-investor-flow`: 외국인 매매를 중심으로 해석
- `samsung-electronics-outlook`: 환율은 보조 변수
- **Gold Case 9**: 환율 자체를 중심 변수로 설명

**필수 내부링크**
- 외국인 수급
- 삼성전자 주가 전망
- SK하이닉스 주가 전망

**작성 Gate**

- 환율 변동성이 커져 검색형 설명 콘텐츠의 필요성이 높아질 때 작성

## Gold Case 10

**핵심 검색 의도**  
SOXX ETF 자체와 미국 반도체 업종 흐름이 한국 반도체주에 어떤 참고 신호가 되는지 알고 싶은 독자.

**가설 키워드**
- SOXX ETF
- SOXX 구성종목
- 미국 반도체 ETF
- SOXX 삼성전자
- 미국 반도체 지수 한국 반도체

**기존 글과의 역할 분리**
- `semiconductor-cycle`: 업황 구조
- 삼성전자·SK하이닉스 글: 개별 종목 판단
- **Gold Case 10**: 미국 시장의 선행·동행 참고지표와 ETF 구조 설명

**필수 내부링크**
- 반도체 사이클
- 삼성전자 주가 전망
- SK하이닉스 주가 전망
- 삼성전자 vs SK하이닉스

**작성 Gate**
- Search Console에서 미국 반도체·ETF 관련 쿼리가 발생하거나
- 10개 Gold Case 완성을 위한 마지막 구조적 빈칸으로 확인될 때 작성

## 우선순위 결정 규칙

D7 전에는 7~10번을 일괄 발행하지 않는다.

D7 이후 아래 순서로 점수를 준다.

| 기준 | 점수 |
| --- | ---: |
| 실제 Search Console 관련 쿼리 발생 | +5 |
| 기존 노출 페이지의 11~20위 쿼리 확장 | +4 |
| 기존 2개 이상 글을 자연스럽게 연결하는가 | +3 |
| 시의성 있는 실제 이벤트가 발생했는가 | +2 |
| 기존 글과 검색 의도가 겹침 | -5 |

점수가 가장 높은 후보부터 작성한다.

동점이면 **Evergreen 검색 의도 → 기존 내부링크 강화 효과 → 시의성** 순으로 결정한다.

## 보류 후보

`미국 금리 인하가 한국 주식에 미치는 영향`은 중요한 주제지만 현재 6개 반도체·수급 클러스터보다 범위가 넓다. Gold Case 11 이후의 매크로 확장 후보로 보류한다.

## 완료 기준

- 7~10번의 검색 의도가 서로 중복되지 않는다.
- 각 글은 기존 2개 이상 글과 내부링크가 가능하다.
- D7 Search Console 데이터가 나오기 전에는 후보 상태를 유지한다.
- 실제 검색 쿼리가 후보 제목보다 더 구체적이면 제목과 목차를 해당 쿼리에 맞춰 수정한 뒤 작성한다.

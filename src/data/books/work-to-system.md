기록은 많아도 다시 찾을 수 없다면 운영 시스템이 아닙니다. 이 책은 상담 현장에서 생긴 짧은 관찰과 Follow-up을 출발점으로, 사람이 기억하던 업무를 데이터와 인터페이스로 옮겨간 과정을 담았습니다.

### 기억 부채에서 시작했습니다

누구에게 다시 확인해야 하는지, 왜 KPI가 바뀌었는지, 어떤 이야기를 지난 면담에서 나눴는지 한 사람이 계속 기억하고 있다면 시스템이 기억해야 할 일을 사람이 대신하고 있는 셈입니다.

Series 02는 이 상태를 **기억 부채**로 정의하고 기록의 양을 늘리는 대신 다시 꺼내 쓸 수 있는 구조를 만듭니다.

### 하나의 원고를 네 가지 출력으로 연결했습니다

동일한 canonical source를 Web Manuscript, Interactive Reader, EPUB3, A5 Print PDF가 함께 사용합니다. EPUBCheck, PDF preflight, Export Provenance, Production Smoke와 JoyLab Release Gate를 거쳐 v1.0.0으로 고정했습니다.

### 읽으면서 자신의 업무 OS를 만듭니다

15개 장마다 기억 부채 진단, Persona 0 Moment, 원문/요약 Pair, Mini Data Contract, KPI 변경 규칙, First Screen, One-line Capture, Context Split 등 직접 입력하는 실습이 연결되어 있습니다.

입력 내용은 브라우저 localStorage에만 저장되며 서버로 전송하지 않습니다.

> 사람의 판단을 없애는 것이 아니라, 사람이 굳이 기억하지 않아도 되는 것부터 시스템에 넘깁니다.

이 책은 완성된 앱을 자랑하는 개발기가 아닙니다. 고객센터 현장에서 리더가 매일 마주하는 **기록 누락, 재점검, KPI 변경, 면담 맥락, 모바일과 PC의 역할 차이**를 하나씩 시스템 문제로 다시 정의한 과정입니다.

### 기록보다 회수가 먼저였습니다

메모를 더 많이 남긴다고 운영이 좋아지지 않았습니다. 필요한 순간에 다시 꺼낼 수 있고, 누구와 연결된 정보인지 알 수 있고, 다음 행동으로 이어져야 했습니다. 그 과정에서 기억파편과 Follow-up, 정식 면담, STT 원문이라는 데이터 단위가 생겼습니다.

### 하나의 앱보다 하나의 흐름을 만들었습니다

현장에서는 20~30초 안에 남기는 모바일 기록기가 필요했고, PC에서는 여러 기록과 KPI를 연결해 판단하는 운영 본체가 필요했습니다. 그래서 **LeaderDesk Coaching**과 **LeaderDesk Ops**를 분리하되 Core Data Contract는 하나로 유지했습니다.

### 읽는 책에서 실행하는 책으로 만들었습니다

Series 02는 15개 Chapter 원고뿐 아니라 15개 Interactive Workbook을 제공합니다. 각 장을 읽고 자신의 업무를 입력해 저장할 수 있으며, 입력 내용은 브라우저 localStorage에만 저장됩니다.

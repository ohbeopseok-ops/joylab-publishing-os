조선주는 모두 같은 업황을 타지만 **돈을 버는 방식은 다릅니다.**

HD현대중공업은 상선·엔진·특수선을 동시에 보유하고, 한화오션은 LNG선과 특수선의 결합이 강합니다. 삼성중공업은 LNG선·해양플랜트에 특화돼 있고, HD한국조선해양은 여러 조선 자산을 묶는 그룹 포트폴리오 플레이입니다.

이 글은 네 회사를 같은 Compare Hub V1 Lens로 비교합니다.

## 1. VALUE CHAIN POSITION｜네 회사는 같은 조선사가 아니다

| 기업 | 핵심 포지션 | 특징 |
| --- | --- | --- |
| HD현대중공업 | 상선·엔진·특수선 | 제조·엔진·함정을 함께 보유 |
| 한화오션 | 상선·특수선·해양 | LNG선과 잠수함·수상함 결합 |
| 삼성중공업 | 상선·해양 | LNG선·FLNG·스마트야드 특화 |
| HD한국조선해양 | 그룹 포트폴리오 | 조선 자회사·엔진·해외야드 자본배분 |

**해석:** 업황이 좋아도 가장 민감하게 반응하는 변수는 회사마다 다릅니다.

## 2. THEME EXPOSURE｜LNG·방산·해양·그룹 시너지

| 기업 | 가장 강한 테마 |
| --- | --- |
| HD현대중공업 | LNG선 + 엔진 + 특수선 |
| 한화오션 | LNG선 + 방산 + 북미 협력 |
| 삼성중공업 | LNG선 + FLNG + 생산 자동화 |
| HD한국조선해양 | 그룹 선별수주 + 해외야드 + 자본배분 |

방산과 미국 조선 협력의 옵션 가치는 HD현대중공업과 한화오션이 상대적으로 높고, 해양플랜트 전문성은 삼성중공업이 강합니다. HD한국조선해양은 개별 테마보다 그룹 전체 이익의 질을 봐야 합니다.

## 3. DEMAND QUALITY / REVENUE VISIBILITY｜수주잔고의 크기보다 질

2026년 6월 말 기준 주요 비교는 다음과 같습니다.

| 기업 | 수주잔고/가시성 | 해석 |
| --- | ---: | --- |
| HD현대중공업 | 고선가 상선·엔진·특수선 | 미포 합병 이후 통합 믹스 확인 필요 |
| 한화오션 | 약 337억달러 | LNG선 + 특수선 비중이 핵심 |
| 삼성중공업 | 약 355억달러 | LNG·해양 프로젝트 원가가 핵심 |
| HD한국조선해양 | 약 761억달러 | 그룹 합산이라 단일사와 직접 비교 불가 |

2026년 신규수주도 HD한국조선해양 그룹 약 **163.9억달러**, 삼성중공업 약 **100억달러**, 한화오션 상반기 약 **43.5억달러** 수준으로 파악됩니다.

**해석:** `잔고가 많다 = 더 좋다`가 아닙니다. 선가·선종·인도연도·원가·고객 집중도를 함께 봐야 합니다.

## 4. CAPACITY & LEAD TIME｜누가 수주를 더 빨리 매출로 바꾸는가

| 기업 | Capacity 핵심 변수 |
| --- | --- |
| HD현대중공업 | 미포 통합, 엔진 증설, 특수선 슬롯 |
| 한화오션 | 거제 생산 안정화, 특수선 확대 |
| 삼성중공업 | 스마트야드·로봇 자동화 |
| HD한국조선해양 | 그룹 조선소 배분 + 해외야드 |

조선업의 다음 차이는 수주가 아니라 **생산성**에서 날 가능성이 큽니다.

## 5. MARGIN TRANSMISSION｜2Q26에서 이미 차이가 보인다

| 기업 | 2Q26 매출 | 2Q26 영업이익 | OPM |
| --- | ---: | ---: | ---: |
| HD현대중공업 | 6조 3,322억원 | 1조 399억원 | 약 16.4% |
| 한화오션 | 5조 4,432억원 | 7,361억원 | 약 13.5% |
| 삼성중공업 | 3조 2,307억원 | 3,250억원 | 약 10.1% |
| HD한국조선해양 | 8조 9,270억원 | 1조 6,451억원 | 약 18.4% |

HD한국조선해양은 그룹 연결 기준이라 단일 조선사와 직접 비교할 때 주의가 필요합니다. 한화오션 역시 해양 프로젝트 매출 약 1.5조원이 반영된 분기라는 점을 감안해야 합니다.

**해석:** 단순 OPM 순위보다 반복 가능한 정상 마진을 봐야 합니다.

| 기업 | 경쟁우위 | 주요 약점 |

## 7. VALUATION & RISK｜좋은 회사와 좋은 주가는 다르다

기준일: **2026-09-10**

| 기업 | 밸류에이션 판단 포인트 |
| --- | --- |
| HD현대중공업 | 높은 마진과 방산·엔진 프리미엄이 얼마나 선반영됐는가 |
| 한화오션 | 상선 정상 이익과 방산 옵션 가치를 분리해야 함 |
| 삼성중공업 | 10% OPM 정착과 해양 리스크 감소가 핵심 |
| HD한국조선해양 | 자회사 가치 대비 지주 할인 축소 가능성 |

조선주는 실적이 좋아져도 이미 높은 기대가 주가에 반영돼 있다면 추가 수익률은 제한될 수 있습니다.

## 8. SCENARIO｜Bull / Base / Bear에서 누가 더 민감한가

### BULL

- LNG 발주와 고선가 유지
- 미국 조선·MRO·특수선 시장 확대
- 생산성 개선으로 두 자릿수 OPM 지속

**상대 민감도:** HD현대중공업·한화오션의 방산 옵션, 삼성중공업의 FLNG, HD한국조선해양의 지주 할인 축소가 추가 레버리지입니다.

### BASE

- LNG·컨테이너선 발주는 정상화하되 수주잔고가 3~4년 매출을 지지
- 원가와 생산성은 안정적
- 마진은 현재보다 일부 정상화

### BEAR

- 신조선가 하락
- 원가·인건비 상승
- 공정 지연
- 특수선 해외 계약 지연
- 높은 밸류에이션 압축

## 결론｜한 줄로 정리하면

- **HD현대중공업:** 제조·엔진·특수선의 가장 넓은 직접 노출
- **한화오션:** LNG선 수익성에 방산 옵션이 가장 강하게 붙는 구조
- **삼성중공업:** LNG·FLNG와 생산 자동화에 집중된 구조
- **HD한국조선해양:** 조선 슈퍼사이클을 그룹 포트폴리오로 사는 구조
